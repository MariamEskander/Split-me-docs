# Split Me — support & privacy

The public support page and privacy policy for the **Split Me** iOS app, served
by GitHub Pages. The App Store requires both URLs before a listing can be
submitted.

- Support and FAQ — [index.html](index.html)
- Privacy policy — [privacy.html](privacy.html)

The policy describes the app as actually built: nothing is collected, receipts
are read on-device by Apple's text recogniser and never uploaded, and the two
optional location uses are documented separately.

The app source lives elsewhere; this repository is only the site.
